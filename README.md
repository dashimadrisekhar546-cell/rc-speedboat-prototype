# Remote-Controlled Speedboat Prototype

Hands-on hobby project combining CAD, fabrication, mechanical assembly, propulsion, and performance testing.

## Project Overview

Designed, fabricated, assembled, and tested a functional remote-controlled speedboat prototype. The project focused on integrating the hull, propulsion system, steering mechanism, and electronics into a lightweight model suitable for water-based testing.

## Highlights

- Designed and fabricated a working speedboat prototype
- Integrated remote-controlled propulsion and steering systems
- Optimized stability, maneuverability, and weight distribution through testing
- Iterated on the design based on observed performance
- Diagnosed and resolved practical mechanical and electrical integration issues

## Skills Demonstrated

- CAD-based mechanical design
- Prototype fabrication and assembly
- Propulsion and steering integration
- Stability and buoyancy evaluation
- Hands-on troubleshooting
- Performance testing and design iteration
